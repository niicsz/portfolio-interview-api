# Experiência profissional no Bradesco

## Cargo e período

Nicolas é Junior Software Engineer no Bradesco desde fevereiro de 2025, no modelo híbrido, em Osasco (SP). Passou por três squads.

## Btoken – Token Corporativo do Bradesco

Na primeira squad, atuou no Btoken, o token corporativo do Bradesco: um sistema de geração de tokens OTP usado em vários canais bancários. Contribuiu para o desenvolvimento e a manutenção do sistema.

Construiu microsserviços com Spring Boot, desenvolveu APIs REST documentadas com Swagger/OpenAPI e implementou testes unitários com JUnit 5 e Mockito. Usou Java, Kafka, Azure, SQL Server e Databricks para persistência de dados, processamento e relatórios analíticos.

## Squad DocMatch – Análise de Documentos

Depois, integrou a squad DocMatch (análise de documentos), desenvolvendo integrações com a API da Serasa para validação e autenticação de documentos. Trabalhou com MongoDB e SQL Server para armazenamento e correlação de dados, garantindo segurança e escalabilidade nos processos de onboarding.

## Squad Bex for Dev – Platform Engineering

Atualmente faz parte da squad Bex for Dev, em um contexto de Platform Engineering com o Backstage (Internal Developer Platform). Apoia iniciativas para melhorar a experiência do desenvolvedor (DX) e mantém serviços da plataforma interna.

O dia a dia inclui Linux (WSL e RHEL), containers com Podman e Docker e criação de shell scripts para automação de tarefas.
