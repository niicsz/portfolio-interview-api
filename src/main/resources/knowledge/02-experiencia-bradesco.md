# Experiência profissional no Bradesco

## Cargo e período

Nicolas é Software Engineer I no Bradesco desde fevereiro de 2025, no modelo híbrido, em Osasco (SP). Passou por três squads: Btoken, DocMatch e, atualmente, Bex for Dev.

## Btoken – Token Corporativo do Bradesco

Na primeira squad, atuou no Btoken, o serviço de autenticação e token corporativo do Bradesco: um sistema de geração de OTP usado em múltiplos canais bancários, que processa mais de 2 milhões de requisições por dia e atende milhões de usuários. Entregou mais de 20 novas funcionalidades no serviço, reforçando a segurança e melhorando a experiência dos usuários.

Melhorou em 500% a performance do serviço de autenticação: analisou e otimizou consultas no SQL Server que eram prejudicadas pelo tratamento ineficiente de VARCHAR.

Projetou e manteve integrações orientadas a eventos com Apache Kafka, garantindo comunicação confiável entre serviços distribuídos.

Atuou no suporte L3: diagnosticava incidentes em produção, fazia análise de causa raiz e implementava correções definitivas para manter a alta disponibilidade do serviço.

Integrou o Source Formatter ao pipeline de CI/CD, melhorando a qualidade, a manutenibilidade e a padronização do código do time. Também liderou melhorias no fluxo de trabalho, com práticas melhores de gestão de tarefas que aumentaram a eficiência do time e a previsibilidade das entregas.

Construiu microsserviços com Spring Boot e APIs REST documentadas com Swagger/OpenAPI. Implementou testes com JUnit 5 e Mockito, alcançando 95% de cobertura no SonarQube. Usou Azure para nuvem, SQL Server para persistência e Databricks para análise de dados.

## Squad DocMatch – Análise de Documentos

Depois, integrou a squad DocMatch (análise de documentos). Desenvolveu integrações com a API da Serasa para validação e autenticação de documentos em onboarding e verificação de identidade, reduzindo o tempo médio de verificação em cerca de 30%.

Trabalhou com MongoDB e SQL Server para armazenamento e correlação de dados, suportando mais de 500 mil validações por mês. Otimizou consultas, reduzindo a latência de 800 ms para 250 ms.

## Squad Bex for Dev – Platform Engineering

Atualmente faz parte da squad Bex for Dev, em Platform Engineering com o Backstage (Internal Developer Platform), apoiando iniciativas de experiência do desenvolvedor (DX) que impactam mais de 500 devs internos. O dia a dia inclui Linux Red Hat (RHEL), tanto em notebooks quanto via WSL, containers com Podman e Docker e scripts Shell para automação.

## Bex for Dev – Linux Red Hat, external images e Bex Dev Local

Na Bex for Dev, Nicolas dá suporte ao piloto de adoção do Linux Red Hat no banco, tanto em notebooks com RHEL quanto via WSL, que permite aos devs escolher entre Linux e Windows no onboarding. Trabalhou na oferta de external images, viabilizando o uso de imagens do Docker Hub livres de CVEs e reduzindo o tempo de provisionamento em cerca de 60%.

Habilitou o GitHub Copilot CLI nas distros Red Hat via WSL e criou o "Bex Dev Local", um script que automatiza setup, build e start do projeto, reduzindo a configuração de ambiente de horas para cerca de 10 minutos.
