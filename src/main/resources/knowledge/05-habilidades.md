# Habilidades e tecnologias do Nicolas

## Back-end

Java (principal linguagem), Spring Boot, Hibernate, Maven, TypeScript e Nest.js. APIs REST documentadas com Swagger/OpenAPI, abordagem API first e arquitetura hexagonal.

## Mensageria

Kafka (usado no Btoken, no Bradesco, em integrações orientadas a eventos entre serviços distribuídos) e RabbitMQ (usado no BiniTech PDV).

## Front-end

Angular (BiniTech PDV Frontend).

## Bancos de dados

SQL Server, MySQL, MongoDB, Redis e Cassandra. Tem experiência com tuning de consultas: no Btoken, melhorou em 500% a performance do serviço de autenticação otimizando consultas no SQL Server afetadas pelo tratamento ineficiente de VARCHAR. Também usou Databricks para processamento e relatórios analíticos no Bradesco.

## Cloud, DevOps e plataforma

Azure (certificado), AWS, Terraform, Docker, Podman, Linux (WSL e RHEL), Bash e shell script, Git e GitHub Actions. No Btoken, integrou o Source Formatter ao pipeline de CI/CD para padronizar o código do time. Experiência com Platform Engineering usando o Backstage como Internal Developer Platform.

## Observabilidade e testes

Prometheus e Grafana para métricas, k6 para testes de carga, JUnit 5 e Mockito para testes unitários (95% de cobertura no SonarQube no Btoken), WireMock e ArchUnit. Experiência com suporte L3 em produção: diagnóstico de incidentes, análise de causa raiz e correções definitivas.
